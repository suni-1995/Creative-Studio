창작소 : 내 손안에 이야기 — fix14 안정화/실사용 테스트 수정본
기준: creative_studio_storyhand_v2_dev_fix13_calendar_width.zip

주요 변경
1) 일기장 캘린더 하단 기록 영역 긴 문자열/URL 가로폭 이탈 방지
2) 다크 모드 프로젝트 지정 색상 표시 보강
3) 설정/캐릭터 그룹 필드 + 그룹별 접기/펼치기 목록
4) 캐릭터 개인 관계(양방향/단방향, 관계명/설명, 프로필 이동) 추가
5) 썰/장문 전체 복사 버튼 + 텍스트 선택/긴 문자열 안정화
6) 썰/장문 파일 아이콘 색상 프리셋
7) 타임라인 세로 연결선/노드 디자인 보강
8) 설정/썰/타임라인 복제 기능 추가
9) 일정 스크롤 이후 맨 위로 ↑ 버튼
10) 설정/썰/타임라인 초안/완성 상태
11) 모달/상세/편집창 오픈 시 내부 스크롤 상단 초기화 보강
12) 글꼴 교체: BMKkubulim / Cafe24 Oneprettynight / HangeulNuri (기본 고딕/명조 유지)

데이터 호환
- 기존 항목에 새 필드가 없어도 기본값으로 동작
- 인물 관계는 characterRelations 별도 배열 사용
- 기존 JSON/ZIP 백업은 characterRelations가 없는 경우 빈 배열로 복원
- 새 필드는 db 메타데이터에 포함되어 JSON/ZIP 백업에 자동 포함
- 썰 이미지 복제는 기존 이미지 참조 재사용
- 설정 음악 및 일기장 타임라인 이미지는 원본 손상을 피하기 위해 필요한 경우 파일 복제

실기기 우선 테스트
- 캘린더 하단에 매우 긴 한글/영문/URL/공백 없는 문자열 입력 후 가로 스크롤 여부
- 다크/라이트 전환 후 프로젝트별 색상 구분
- 설정/캐릭터 그룹 생성, 미분류, 접기/펼치기, 검색/태그/정렬 병행
- 썰 편집 중 복사/붙여넣기/전체 복사와 키보드 포커스
- 설정/썰/타임라인 복제 후 원본/복제본 각각 수정
- 인물 관계 A↔B, A→C 생성 후 양쪽 프로필 표시 및 이동
- 긴 목록/긴 모달에서 ↑ 버튼
- 모달 여러 번 열고 닫을 때 항상 상단 시작
- 폰트 3개 각각 적용 후 버튼/카드/제목 가로폭 확인
- ZIP 전체 백업/복원 후 그룹/상태/아이콘색/인물관계 유지 확인

정적 점검
- JavaScript 구문 검사(node --check) 통과
- 폰트 assets 존재 확인
- fix14 CSS 중복 삽입 여부 확인
