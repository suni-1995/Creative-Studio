창작소 : 내 손안에 이야기

새 설치 전용 버전입니다.
기존 창작소와 다른 패키지명을 사용하므로 별도 앱으로 설치됩니다.

빌드:
Android Studio에서 이 폴더를 연 뒤 Gradle 동기화가 끝나면
Build > Generate App Bundles or APKs > Generate APKs

주요 변경:
- Light / Dark 테마 버튼
- 모든 선택 메뉴를 앱 테마형 선택창으로 통일
- 상단 문구: 창작소 : 여러 이야기를 한 손에
- 앱 이름: 창작소 : 내 손안에 이야기
- PDF: 제목 / 기본정보 표 / 본문 구조로 가독성 개선

- 썰/장문 편집 영역 내부 스크롤 보강
